# 朔到望间隔的简化理论分布

这是一个明确假设下的解析模型，不使用已有 2,473 个样本，不拟合样本极值，也不是 DE440 的完整理论概率律。

假设月相角 D(t)=w t+2e[sin(φ+n_a t)−sinφ]，其中 w=2π/S，S=29.530589 天，n_a=2π/P_a，P_a=27.554550 天，e=0.0549。φ 表示朔时的月球平均近点相位，并假设在 [0,2π) 上均匀分布。

求 D(T)=π，在 μ=π/w 附近保留 e 的一阶项，得到

T≈μ−(4e/w)sin(n_a μ/2)cos(φ+n_a μ/2)。

因此 T 是平移缩放的反正弦分布，密度为

f(t)=1/[π√(A²−(t−μ)²)]，|t−μ|<A。

相位在时间间隔的极大和极小附近变化时，间隔本身变化缓慢，所以相同宽度的时间格收集到更多相位。注意这里描述的是“间隔随朔时轨道相位的变化”，不是简单地把月球在远地点走得慢直接当成分布推导。

图中纵轴是概率密度，每段概率等于曲线下面积。两端的密度趋于无穷但可积，任意有限分钟格的概率都是有限的，单个精确时长的概率为零。图中纵轴只显示至 1.65/天，端部高密度被截取。

`analytic_bins_1minute.csv` 则与此前的分钟分箱对应：以整数分钟为边界，每格概率直接由解析 CDF 相减得到，总和为 1，没有随机抽样。

太阳摄动、尤其月球出差等周期项，会显著改变这个简单模型的振幅；其他周期还会展宽和改变两端峰形。因此不能把图中的理论支撑区间当成真实月球的精确范围，也不能据此直接推算农历十五或十六的概率。

若要求更接近实际的“理论长期分布”，还需指定动力学模型、研究年代，以及如何对轨道相位或朔望周期加权。在完整模型中可用连续相位积分或确定性数值积分，增加同样 200 年的计算位数不会增加独立朔望事件数。

复现：在项目根目录运行 `.venv\Scripts\python.exe -X utf8 theory.py`。

平均参数来源：[NASA 月球轨道](https://eclipse.gsfc.nasa.gov/help/moonorbit.html)、[NASA 食周期](https://eclipse.gsfc.nasa.gov/LEsaros/LEperiodicity.html)。
